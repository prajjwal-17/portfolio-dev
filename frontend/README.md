# Prajjwal Rawat - Portfolio

Next.js (App Router) + Tailwind CSS v4.

- `/` - interactive terminal with a physics-based 3D ID badge
- `/recruiter` - conventional recruiter view
- `/projects/[slug]` - architecture diagram and deep dive per project

Content lives in `data/`. Terminal commands are in `lib/commands.js`.

```bash
npm install
npm run dev
```
